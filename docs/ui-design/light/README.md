# 淺色配色提案：冷白、銅綠與淡銅

採用「更明顯的訊息底色」版本。此處保存配色與介面示意，供後續 app 的淺色主題實作使用。

## 預覽

- [preview.html](preview.html)：可用瀏覽器直接開啟的完整預覽，預設即為採用的配色。
- [preview.fragment.html](preview.fragment.html)：可編輯的預覽來源。

預覽中的人物與訊息為示例資料；輸入的文字只加入當前頁面的示意，不會傳送或儲存。它呈現列表、聊天、未讀數、等待與失敗狀態；窄視窗只顯示聊天畫面。

## 配色

下表使用 app 現有的變數名稱。預覽為避免與外層頁面衝突，使用獨立的 `--estoc-*` 名稱。

| 用途 | app 變數 | 色值 |
| --- | --- | --- |
| 聊天背景、輸入區內側 | `--ground` | `#EDF2F4` |
| 列表、頂欄、輸入區外側 | `--surface` | `#F7F9FA` |
| 浮起的卡片、選中列的頭像底色 | `--raised` | `#FFFFFF` |
| 分隔線 | `--line` | `#D3DFE3` |
| 主要文字 | `--ink` | `#233238` |
| 次要文字、時間、說明 | `--ink-soft` | `#495E65` |
| 操作、頭像字母、未讀數、連線狀態 | `--accent` | `#2D6A58` |
| 強調色底上的文字與圖示 | `--on-accent` | `#FFFFFF` |
| 收到的訊息、頭像、選中的對話 | `--verdigris-wash` | `#D1E4DB` |
| 送出的訊息 | `--copper-wash` | `#E8D9CD` |
| 失敗、未送出 | `--alarm` | `#A54430` |
| 等待、需要留意 | `--attention` | `#795916` |
| 提醒背景 | `--attention-wash` | `#F2E8CE` |

## 設計關係

- 整體維持冷色背景，以冷灰、近白與白色建立層次。畫面內使用亮度差與細線分隔，陰影留給覆蓋畫面的抽屜與彈窗。
- 收到的訊息是銅綠，送出的是淡銅色。兩種底色維持相近的視覺重量，共用深灰文字，並保留左右位置與尾角作為辨識線索。
- 以深銅綠作為單一操作強調色，讓按鈕、連結與焦點在淺底上清楚可見。
- 次要文字與狀態色需在實際底色上保持可讀性。等待與錯誤同時以文字表達，不只靠顏色區分。
- 字體、字級、圓角與導覽結構沿用既有設計語言；預覽內容不代表新增產品功能。

## 實作時需補齊

本提案尚未涵蓋 `--line-strong`、`--scrim`、`--shadow`，也未呈現所有表單、抽屜與彈窗。接入 app 時需配合實際畫面補齊，並檢查焦點、停用、懸停與下拉箭頭等狀態；不能只替換主色表。

主題切換方式與偏好儲存方式另行決定。
